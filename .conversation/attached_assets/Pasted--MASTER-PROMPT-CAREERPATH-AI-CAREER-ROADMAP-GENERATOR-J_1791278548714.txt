2. Validate the incoming request using Zod.
3. Enforce reasonable request-size and rate limits.
4. Read GEMINI_API_KEY from server-side environment variables.

6. Validate the returned JSON against a defined schema.
7. Reject malformed or incomplete responses.
8. Return safe errors without exposing credentials.
9. Save validated roadmaps and associated tasks in Supabase.
10. Return the saved roadmap to the frontend.
